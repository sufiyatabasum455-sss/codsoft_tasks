## Task: Nginx Web Server

### Objective
Deploy a static website using Nginx on Ubuntu.

### Tools Used
- Ubuntu
- Nginx
- HTML
- Linux Terminal

### Steps Performed

1. Installed Nginx on Ubuntu.
2. Started the Nginx web server.
3. Created a static HTML webpage.
4. Saved the webpage as:
   `/var/www/html/index.html`
5. Tested the website using:
   `curl http://localhost`
6. Verified that the webpage was successfully served by Nginx.
